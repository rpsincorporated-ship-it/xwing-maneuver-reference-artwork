SECOND EDITION (2.0) MANEUVER FILES
-----------------------------------
Save one file per unique ship type in images/maneuvers/2.0/ using:

xwing-2.0-<ship-slug>-maneuver.png

Examples:
xwing-2.0-t-65-x-wing-maneuver.png
xwing-2.0-tie-ln-fighter-maneuver.png
xwing-2.0-rz-2-a-wing-maneuver.png

MANEUVER DIAL FILES
-------------------
Save one physical dial image per ship type. Keep dials separate from maneuver
charts. Use these folders and filename patterns:

images/dials/1.0/xwing-1.0-<ship-slug>-dial.png
images/dials/2.0/xwing-2.0-<ship-slug>-dial.png

For split huge ships, use one dial per physical ship, not separate Fore/Aft
dials.

PILOT AND SHIP CARDBOARD TOKENS
-------------------------------
Save ship cardboard tokens in:

images/ship-tokens/1.0/xwing-1.0-<ship-slug>-ship-token.png

images/ship-tokens/2.0/xwing-2.0-<pilot-slug>-pilot-token.png

FILE NAMING RULES
-----------------
Use lowercase filenames, replace spaces with hyphens, and keep edition numbers
in every filename. Keep First Edition and Second Edition artwork in separate
folders. Do not combine maneuver charts, printed dials, ship tokens, pilot
tokens, and status tokens in the same folder.
