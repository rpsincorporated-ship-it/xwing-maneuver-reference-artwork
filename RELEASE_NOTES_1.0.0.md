# X-Wing Maneuver Reference Artwork 1.0.0

## Release summary

This release provides the initial public maneuver-artwork package for X-Wing First Edition and Second Edition.

## Included

- First Edition maneuver artwork under `images/maneuvers/1.0/`
- Second Edition maneuver artwork under `images/maneuvers/2.0/`
- Huge-ship maneuver references where applicable
- Edition-specific naming and folder structure
- Import manifest and artwork audit documentation

## Not included

- Maneuver dial images
- Ship cardboard or tokens
- Pilot or upgrade card artwork
- Syliure-class hyperspace ring maneuver artwork, because it has no maneuver table

## Use

Download or clone the repository and point your compatible application at the appropriate edition folder. For print use, verify scale and printer settings before cutting or using any reference at the table.
